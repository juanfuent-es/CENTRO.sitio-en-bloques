# Moodboard y referencias

## Buscar antes de diseñar

**Tagline:** Las referencias ayudan a tomar decisiones visuales con intención.

**Descriptor:** Un moodboard reúne materiales visuales que orientan el estilo del proyecto. No se trata de copiar una imagen, sino de observar color, tipografía, composición, ritmo, textura, atmósfera y recursos de interfaz.

## Objetivo

Construir una base visual para tomar decisiones. Las referencias sirven para justificar el sistema visual y evitar elecciones al azar.

## Cómo se consigue

Se consigue buscando, seleccionando y comentando referencias.

Cada referencia debe responder:

- qué es;
- por qué se eligió;
- qué se puede aprender de ella;
- cómo se relaciona con el proyecto.

## Subtemas

### Referencias visuales

Pueden venir de:

- sitios web;
- portadas;
- carteles;
- libros;
- interfaces;
- revistas;
- fotografía;
- identidad visual;
- archivos;
- piezas culturales relacionadas con el tema.

### Moodboard

Un moodboard puede hacerse en Figma, Illustrator, Photoshop, Canva, Milanote o con capturas organizadas en una carpeta.

Lo importante es que haya evidencia visual.

### Lectura de referencias

No basta con pegar imágenes. Hay que observar.

Ejemplo:

| Referencia | Qué recupero |
|---|---|
| Poster musical | Contraste alto, tipografía display, composición densa |
| Sitio editorial | Márgenes amplios, cuerpo legible, jerarquía clara |
| Archivo fotográfico | Tono documental, imágenes al centro, colores neutros |

### Relación con el sistema visual

Las referencias deben alimentar decisiones concretas:

- colores;
- tipografías;
- composición;
- estilo de imagen;
- ritmo;
- densidad;
- botones;
- navegación.

## Evidencia esperada

El proyecto debe incluir:

- screenshots o imágenes de referencia;
- enlaces cuando sea posible;
- notas breves sobre qué se recupera;
- relación con tono y sistema visual.

## Errores comunes

- Poner referencias sin explicación.
- Usar referencias que no se relacionan con la intención.
- Copiar una referencia sin adaptarla.
- Elegir colores sin revisar contraste.
- No explorar tipografías antes de decidir.

## Preguntas de revisión

- ¿Mis referencias tienen relación con el tema?
- ¿Estoy observando forma, no solo contenido?
- ¿Qué color puedo recuperar?
- ¿Qué tipo de composición aparece?
- ¿Qué tipografía tiene sentido para mi tono?
