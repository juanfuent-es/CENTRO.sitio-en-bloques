# Mapa de sitio

## Secciones, recorrido y navegación

**Tagline:** Un mapa de sitio muestra cómo se organiza y se recorre la información.

**Descriptor:** El mapa de sitio permite ver la estructura general antes de diseñar pantallas. Incluso en una sola página, ayuda a decidir qué secciones existen, cómo se ordenan y cómo se navegan.

## Objetivo

Construir una visión general del sitio. El mapa ayuda a revisar si hay demasiadas secciones, si falta información o si el recorrido tiene sentido.

## Cómo se consigue

Se consigue agrupando la información estructurada en secciones navegables.

Ejemplo:

```text
Inicio
  Hero
  Contexto
  Categorías principales
  Ejemplos
  Cierre / CTA
```

## Subtemas

### Secciones

Una sección agrupa información relacionada. No cada dato necesita ser una sección.

Ejemplo:

| Mal síntesis | Mejor síntesis |
|---|---|
| 40 tipos de hongos como 40 secciones | 7 tipos de suelo como categorías principales |
| 20 proyectos en el menú | 4 tipos de problema o 5 casos seleccionados |
| Todos los datos en el hero | Hero como entrada + secciones para profundizar |

### Navegación

La navegación debe ser posible de leer y usar.

Si el menú tiene demasiadas entradas, probablemente falta síntesis.

### Layout

El mapa de sitio no es todavía diseño visual, pero anticipa layout:

- qué aparece primero;
- qué bloques se repiten;
- qué secciones necesitan imágenes;
- qué secciones necesitan listas;
- qué secciones necesitan botones;
- qué puede vivir como detalle secundario.

### Recorrido

El orden de secciones construye una narrativa.

Una estructura básica puede ser:

1. entrada;
2. contexto;
3. desarrollo;
4. ejemplos;
5. cierre.

## Evidencia esperada

El proyecto debe incluir un mapa de sitio en Markdown. Puede ser una lista jerárquica.

Ejemplo:

```md
# Mapa de sitio

- Inicio
  - Hero
  - Introducción
  - Categorías
  - Casos
  - Cierre
```

## Errores comunes

- Confundir mapa de sitio con menú visual.
- Tener demasiadas secciones.
- Repetir secciones con nombres distintos.
- No distinguir sección principal de subsección.
- No conectar las secciones con la intención comunicativa.

## Preguntas de revisión

- ¿Mi mapa de sitio cabe en una navegación sencilla?
- ¿Las secciones están relacionadas entre sí?
- ¿El orden ayuda a entender el tema?
- ¿Estoy repitiendo información?
- ¿Puedo agrupar mejor?
