# Ejemplo: portafolio / perfil profesional

## Selección de casos

**Tagline:** Cada problema, una solución diferente.

**Descriptor:** Este ejemplo muestra cómo un perfil profesional puede organizarse como un sitio de portafolio. La intención no es listar todo, sino seleccionar proyectos que expliquen una manera de pensar, analizar y construir.

## Objetivo

Mostrar un perfil capaz de cruzar diseño, código, docencia y dirección de proyectos sin convertir el sitio en un currículum largo.

## Información inicial

Posibles entidades:

- perfil profesional;
- proyectos;
- clientes;
- herramientas;
- problemas resueltos;
- roles;
- contacto.

Posibles atributos de proyecto:

| Atributo | Función |
|---|---|
| Nombre | Identifica el caso |
| Problema | Explica el punto de partida |
| Rol | Define participación |
| Solución | Resume la respuesta |
| Herramientas | Muestra stack o medios usados |
| Resultado | Presenta evidencia o impacto |

## Intención comunicativa

Comunicar un perfil técnico-creativo que analiza problemas antes de elegir herramientas, y que puede construir soluciones distintas según el contexto.

## Mapa de sitio

```text
Inicio
  Hero
  Perfil breve
  Selección de casos
  Forma de trabajo
  Contacto
```

## Tono verbal

- Directo.
- Profesional.
- Claro.
- Con personalidad.
- Sin sonar genérico.

Ejemplos de frases:

- "Cada problema pide una forma distinta de construirse."
- "Diseño y código desde el análisis del problema."
- "Selección de casos: problemas que pudieron resolverse."

## Tono visual

- Pocos colores.
- Tipografía fuerte en títulos.
- Cuerpo legible.
- Mucho espacio.
- Bloques claros.
- Énfasis en jerarquía.

## Aprendizaje del ejemplo

El portafolio no necesita mostrar todo. Puede organizarse como una selección de problemas y soluciones. La estructura ayuda a que el perfil se entienda como práctica, no solo como lista de habilidades.
