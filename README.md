## Qué se va a construir

Cada estudiante desarrollará un sitio web sencillo compuesto por secciones verticales. En esta etapa no se trabajará con `flex`, `grid`, tablas ni JavaScript. El enfoque está en:

- organizar información;
- definir intención;
- construir jerarquía;
- diseñar secciones;
- crear un sistema visual mínimo;
- traducir la estructura a HTML/CSS;
- comprobar que el sitio funcione en desktop y mobile.

## Idea central

Un sitio web no es texto plano.

Markdown permite documentar información con jerarquía. HTML permite convertir esa estructura en una página. CSS permite definir cómo se ve y cómo se lee. El proyecto consiste en hacer visible ese proceso.

## Cómo usar este repositorio

1. Leer la [actividad](actividad.md).
2. Revisar la [rúbrica](rubrica.md) antes de empezar.
3. Consultar los temas según el avance del proyecto.
4. Usar los ejemplos como referencia de proceso, no como formato obligatorio.
5. Construir la entrega con evidencias claras.

## Criterio general

La evaluación no busca premiar complejidad técnica. Busca revisar si hay un proceso consciente: investigar, estructurar, sintetizar, diseñar y construir con claridad.
